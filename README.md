# pio-esp32-s3-touch-amoled-1.8
Demo for the esp32s3 1.8inch amoled touch display from Waveshare on Platformio
Esp32s3 used: https://www.waveshare.com/wiki/ESP32-S3-Touch-AMOLED-1.8

This repo contains all the examples from the waveshare wiki tanslated to Platformio

You can find in each project the board json that worked for me. 
This board definition might change across projects according to the changes made in Arduino IDE in the Waveshre wiki
